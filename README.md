# Pattern CAD - Clean Math Engine / CAD Sewing Pattern Prototype

Python-based prototype for generating and constraining sewing patterns using custom mathematical and geometric logic.

**Core Features**
- Built-from-scratch constraint engine
- Vector rendering with Pycairo
- Ready for future SVG/PDF export

**Technologies**
Python • Pycairo • Clean Architecture (domain/kernel/services)

Personal project — Actively developed.
